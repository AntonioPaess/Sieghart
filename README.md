# Sieghart

Sieghart is a native macOS SwiftUI personal context assistant. The project begins with an experimental Mac accelerometer reader and a local Pomodoro action, then grows toward calendar, reminders, voice, AI, and notch experiences.

The Xcode project is located at [`Sieghart/Sieghart.xcodeproj`](Sieghart/Sieghart.xcodeproj). The detailed product plan and execution log live in the Obsidian vault.
