# Sieghart

Sieghart is a native macOS SwiftUI personal context assistant. The project begins with an experimental Mac accelerometer reader, configurable impact actions, a local Pomodoro action, and a native face-only widget near the notch, then grows toward calendar, reminders, voice, and AI experiences.

The Xcode project is located at [`Sieghart/Sieghart.xcodeproj`](Sieghart/Sieghart.xcodeproj). The detailed product plan and execution log live in the Obsidian vault.
