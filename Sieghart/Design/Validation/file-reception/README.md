# Native file reception preview

`toni-file-receive.mp4` is the current receiver choreography: Toni opens the top aperture, receives the paper and settles. It is a 512×512, 60 fps, 2.6-second isolated native SceneKit export, composited on black. The main Sig Companion and his approved introduction are unchanged.

The six sets of `*-receive-*.png` are deterministic shared-rig geometry checks, not six selectable file receivers. Toni is the fixed file reception owner in the app.

The full widget layout is captured separately in `../sprint-5/`: left/right, top/bottom, diagonal corner, reduced-motion receiver positions and the final attachment. These are offscreen fixtures; actual Finder drag delivery and whole-app CPU still require the user's acceptance test.
